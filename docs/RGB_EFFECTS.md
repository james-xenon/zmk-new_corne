# Eyelash Corne — Smooth RGB36 Effects

Этот файл является только документацией. Он не подключается к CMake/West и не компилируется в прошивку.

## Куда положить

Рекомендуемый путь в основном репозитории:

```text
zmk-new_corne/
├── docs/
│   └── RGB_EFFECTS.md
├── patches/
│   └── rgb_underglow.c
└── ...
```

`docs/RGB_EFFECTS.md` не влияет на бинарник прошивки и не конфликтует с ZMK.

Если не хочешь, чтобы изменение только документации запускало GitHub Actions, можно дополнительно добавить `docs/**` в `paths-ignore` workflow. Это необязательно для работы прошивки.

## Как устроена плавность

- Все эффекты сначала формируют целевой RGB-кадр.
- Физические LED плавно догоняют целевой кадр через общий temporal smoothing.
- При переключении эффекта сохраняется предыдущий отображаемый кадр, поэтому переход получается как мягкий crossfade.
- Sparkle/Fire/Twinkle/Fireflies/Candle/Embers/Galaxy используют интерполяцию между детерминированными случайными ключевыми кадрами — без резкого ON/OFF.
- Параметр `EYELASH_RGB_SMOOTH_DIVISOR` в `rgb_underglow.c`: `3` быстрее, `4` по умолчанию, `5` ещё мягче.

## Совместимость

- Старые внутренние ID эффектов 0–15 сохранены.
- Структура `rgb_underglow_state` не расширена, поэтому формат сохранённых settings не меняется.
- Для логичного листания RGB_EFF/RGB_EFR используется отдельная таблица порядка эффектов.
- Раскладка рассчитана на 21 LED на половину: 3 логических ряда × 7 логических колонок.

## Группы

1. **Base / Color** — Solid → Shimmer.
2. **Motion / Spatial** — Scanner → Soft Rain.
3. **Particles / Atmosphere** — Sparkle → Northern Lights.

Такой порядок выбран специально, чтобы при последовательном переключении соседние эффекты были визуально родственными, а не случайной смесью.
