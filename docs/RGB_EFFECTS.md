# Eyelash Corne — RGB-эффекты (обновлённая спецификация)

Документация для `patches/rgb_underglow.c` в репозитории `james-xenon/zmk-new_corne`, ветка `blink-off`. Этот Markdown-файл сам по себе в прошивку не компилируется.

## Важные принципы

- Существующие внутренние ID эффектов `0–35` сохранены. Новый эффект `Column Pulse` получает ID `36`.
- Структура `rgb_underglow_state` не изменяется: формат сохранённых ZMK settings остаётся прежним.
- В списке `RGB_EFF` / `RGB_EFR` эффекты сгруппированы по характеру движения. Статические режимы поставлены в самый конец.
- Общий temporal smoothing сохранён. Переходы между кадрами и эффектами остаются плавными; случайные анимации используют детерминированные значения и интерполяцию между ключевыми кадрами.
- Текущая физическая карта LED не переопределяется. Эффекты, работающие по семи логическим колонкам, продолжают считать три LED одной колонки одной группой — это соответствует наблюдаемому поведению клавиатуры и не требует повторной диагностики разводки.

## Управление цветом

### Одноцветные эффекты

`RGB_HUI` / `RGB_HUD` меняют основной оттенок, `RGB_SAI` / `RGB_SAD` — насыщенность, `RGB_BRI` / `RGB_BRD` — яркость, `RGB_SPI` / `RGB_SPD` — скорость анимации. Пространственные эффекты могут менять яркость по колонкам, но оттенок берут из выбранного пользователем цвета.

### Эффекты с несколькими цветами

Для Ocean, Sunset, Forest, Lava, Fire, Fireflies, Candle, Embers, Soft Rain, Galaxy, Northern Lights и Matrix используется настраиваемая палитра:

- В исходном положении оттенка (значение `CONFIG_ZMK_RGB_UNDERGLOW_HUE_START`, сейчас `160`) сохраняется привычная цветовая идея эффекта.
- `RGB_HUI` / `RGB_HUD` сдвигают всю палитру по цветовому кругу. Относительное расположение оттенков внутри палитры сохраняется: огонь остаётся градиентом, океан — волнами соседних тонов, Galaxy — фоном со звёздами.
- `RGB_SAI` / `RGB_SAD` масштабируют насыщенность палитры, не разрушая её цветовые соотношения.
- `RGB_BRI` / `RGB_BRD` меняют общую яркость, `RGB_SPI` / `RGB_SPD` — скорость.

Это даёт много вариантов цвета без добавления новых состояний в сохранённую структуру прошивки. Для Flame/Fire/Candle/Embers меняется цветовая основа, а не физика анимации: плавные разгорания, затухания и контраст между фоном и яркими участками сохраняются.

`Spectrum`, `Swirl` и радужные эффекты специально используют широкий цветовой диапазон; для них выбранный оттенок не должен превращать анимацию полного спектра в одноцветную.

## Почему похожие эффекты сохранены

- **Meteor / Comet / Dual Comet** различаются длиной хвоста и количеством голов.
- **Scanner / Dual Scanner / Center Out / Edge In** используют разную геометрию движения.
- **Sparkle / Twinkle / Fireflies / Galaxy** имеют разные плотность частиц, распределение и характер затухания; Sparkle синхронизирован по колонкам, Twinkle — по индексам LED.
- **Rainbow Wave / Moving Gradient / Swirl / Column Rainbow** различаются шириной палитры, её движением и тем, используют ли они логические колонки или физический порядок цепочки.
- **Fire / Candle / Embers / Fireflies** тематически близки, но отличаются частотой события, фоном и поведением затухания.

Точных дубликатов, которые разумно удалить вместо настройки, нет. Поэтому все прежние эффекты сохранены, их ID не перенумерованы.

## Геометрия LED

Эффекты, работающие по колонкам, используют текущую карту `3 ряда × 7 колонок`: все LED одной логической колонки получают согласованную яркость. Для Column Pulse это сделано намеренно. Twinkle/Galaxy продолжают строить случайные значения по индексу LED — без изменения физической карты или попытки переопределить распайку.

## Технические ограничения и совместимость

- Изменения относятся к `patches/rgb_underglow.c` и не требуют изменения `config/eyelash_corne.conf`, `config/eyelash_corne.keymap`, драйвера WS2812 или логики батарейных вспышек.
- `rgb_underglow_state` и существующие ID `0–35` должны остаться без изменений.
- Новый ID `36` добавляется в конце enum; при сохранённом старом эффекте он продолжит загружаться под прежним номером.
- Перед прошивкой обязательно проверить все варианты сборки GitHub Actions. Этот документ описывает целевое поведение и сам не является подтверждением успешной компиляции.
